# AI Model Code Evaluator & Tester

A rigorous automated testing framework built in Python to benchmark, review, and evaluate the logic of AI-generated responses. This system specializes in stress-testing code outputs using regular test cases and edge cases (such as negative integer handling and empty string parameters).

## Features
- **Addition Tester:** Validates mathematical logic and captures edge cases with negative values.
- **String Length Counter:** Evaluates character formatting and handles potential bugs regarding empty strings.
- **Detailed Analytics:** Generates clear logs pinpointing whether the model fails due to standard syntax flaws or unexpected inputs.

## How to Run
Ensure you have Python installed, then run the script via terminal:
```bash
python ai_code_evaluator.py
```
